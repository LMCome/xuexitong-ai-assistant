## 📖 项目介绍

这是一个针对**超星学习通（超星泛雅/学习通APP网页版）**的油猴脚本，在原有满分助手的基础上进行二次开发，集成了主流大语言模型API，实现了：

- 自动完成视频、音频任务点
- 自动检索题库答案
- 题库找不到答案时自动调用AI回答
- 自动填入答案并提交
- 可视化配置面板

## ✨ 功能特性

### 🎯 核心功能
- ✅ **自动视频播放**：16倍速静音自动播放视频任务点
- ✅ **自动音频播放**：自动播放音频任务点
- ✅ **自动答题**：章节测验、作业、考试自动搜题填答案
- ✅ **自动切换章节**：完成后自动跳转到下一章节
- ✅ **自动提交**：答完自动提交试卷/作业

### 🤖 AI答题功能
- ✅ **多模型支持**：DeepSeek / OpenAI / Kimi / 智谱GLM / 通义千问
- ✅ **全题型覆盖**：单选、多选、判断、填空、简答、名词解释、论述、计算
- ✅ **智能匹配**：自动识别选项文本、数字、字母答案
- ✅ **答案拆分**：填空题自动按空拆分答案
- ✅ **可视化配置**：在配置面板直接填写API Key

### 🎨 界面体验
- ✅ **悬浮面板**：可拖动的悬浮助手按钮
- ✅ **运行状态**：实时显示答题进度和当前题目
- ✅ **运行日志**：记录所有操作日志
- ✅ **自动保存**：配置修改后自动保存

## 🚀 安装方法

### 第一步：安装油猴扩展
根据你的浏览器选择安装：
- **Chrome/Edge**：[Tampermonkey（篡改猴）](https://www.tampermonkey.net/)
- **Firefox**：[Violentmonkey（暴力猴）](https://violentmonkey.github.io/)

### 第二步：安装脚本
点击下面的链接，会自动弹出油猴安装确认页面：

👉 [**点击安装学习通AI满分助手**](https://raw.githubusercontent.com/LMCome/xuexitong-ai-assistant/main/xuexitong-ai-assistant.user.js)

或者：
1. 下载 `xuexitong-ai-assistant.user.js` 文件
2. 直接拖入浏览器窗口
3. 油猴扩展会自动识别并弹出安装页面

### 第三步：配置AI API
1. 打开任意超星学习通页面
2. 点击右下角绿色的"满分助手"按钮
3. 点击"设置/授权码"
4. 切换到"AI答题"标签页
5. 开启"启用AI答题"
6. 填写你的API Key和API地址
7. 刷新页面即可生效

## 📖 使用说明

### 基础配置
- **通用间隔**：脚本运行切换的间隔时间（秒），默认3秒
- **答题间隔**：每道题之间的等待时间（秒），默认3秒
- **最低正确率**：低于此正确率不会自动提交，默认80%

### 章节配置
- **自动答题**：开启后自动答章节测验
- **自动视频**：开启后自动播放视频
- **自动切换**：开启后自动切换到下一章节
- **自动提交**：开启后自动提交答案

### AI配置
- **启用AI答题**：题库找不到答案时自动调用AI
- **AI服务**：你使用的AI服务名称（显示用）
- **API地址**：对应AI服务的API基础URL
- **模型名称**：对应AI服务的模型名称
- **API Key**：在对应平台申请的API密钥

## ❓ 常见问题

### Q: 为什么没有看到悬浮按钮？
A: 请确保：
1. 脚本已启用
2. 页面是超星学习通的域名（chaoxing.com等）
3. 刷新页面

### Q: AI答题不生效？
A: 请检查：
1. 是否开启了"启用AI答题"开关
2. API Key是否正确
3. API地址是否正确
4. 控制台（F12）是否有错误信息

### Q: 多选题选不对？
A: AI回答的格式可能不规范，可以在配置里调整提示词，或者手动检查。
